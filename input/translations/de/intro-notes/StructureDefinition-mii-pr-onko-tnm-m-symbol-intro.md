Dieses Profil bildet das m-Symbol einer TNM-Klassifikation ab.
Das m-Symbol gibt das Vorhandensein multipler Tumore an.

Die explizite Verwendung von `m` kodiert für mehrere Tumore, wobei die genaue
Anzahl unbekannt ist. Statt `m` kann auch eine spezifische Anzahl angebenen
werden.

Das m-Symbol ist von der M-Kategorie für die Bewertung von Fernmetastasen
abzugrenzen.
